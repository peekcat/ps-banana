# 工厂工具预设目录

这个目录放矩形选框工具的预设文件 (.tpl), 插件首次启动时**静默导入**到 PS, 让用户选生图比例时 PS 工具栏自动跟着切样式。

## 需要的文件

**`修图轮椅预设.tpl`** — 必须**完全一致**的文件名

里面应该包含 8 个预设:
- 修图轮椅_1:1 (固定比例 1:1)
- 修图轮椅_16:9 (固定比例 16:9)
- 修图轮椅_9:16 (固定比例 9:16)
- 修图轮椅_4:3 (固定比例 4:3)
- 修图轮椅_3:4 (固定比例 3:4)
- 修图轮椅_3:2 (固定比例 3:2)
- 修图轮椅_2:3 (固定比例 2:3)
- 修图轮椅_Auto (样式 = 正常, 无固定)

## 如何生成

1. 在 PS 里手动建好 8 个预设 (你已经做过了)
2. 顶部菜单 `编辑 → 预设 → 预设管理器`
3. 类型选 **"工具"**
4. **按住 Ctrl** 一个个点选 8 个 `修图轮椅_xxx` 预设
5. 点 **"存储设置..."**
6. 文件名填 `修图轮椅预设.tpl`
7. 保存到这个目录 (`factory_presets_tpl/`)

完成后, 重启插件 → 切个比例 → 静默自动导入 + 切预设。

## 重要

- 文件名必须是 `修图轮椅预设.tpl` (大小写不敏感, 但建议小写后缀)
- 不要改预设的中文名 (`修图轮椅_16:9` 这种), 否则插件查不到
