# 高级功能指南

高级功能位于「高级」标签页，以卡片网格形式展示，点击进入对应功能的完整页面。

## 全局分区计算

### 功能

将一张大图自动切分为多个区域，分别发送给 AI 处理后贴回。适合需要对整张图进行统一风格化处理的场景。

### 分区策略

- **横图**（宽 > 高）：切分为左上 + 右上两个区域
- **竖图**（高 > 宽）：切分为左上 + 左下两个区域
- **正方形**：整张图作为一个区域处理

### 使用步骤

1. 进入高级 → 全局分区计算
2. 输入提示词（会应用到所有分区）
3. 选择 API 引擎、模型、分辨率、每区数量、超时
4. 调整蒙版内收和模糊值（控制分区之间的过渡区域）
5. 点击「刷新」获取当前打开的 PS 文档列表
6. 勾选要处理的文档
7. 点击「开始全局分区计算」

### 蒙版参数

- **蒙版内收**（默认400px）：每个分区边缘向内收缩的像素数
- **蒙版模糊**（默认200px）：蒙版边缘的模糊半径，确保分区之间自然过渡

## 分块放大（Tiled Upscale）

### 功能

将大图切分为 2048×2048 的正方形块，逐块发送给 AI 增强后贴回。适合对大尺寸图片进行纹理增强或超分辨率处理。

### 使用步骤

1. 进入高级 → 分块放大
2. 输入纹理增强类提示词
3. 设置重叠量（默认256px，控制相邻块的重叠区域）
4. 点击「开始分块放大」
5. 可选：点击「可视化测试」查看分块划分效果

### 注意

- 重叠区域需要手动用 PS 画笔修补接缝
- 块大小固定为 2048×2048

## 3D 镜头控制

### 功能

通过交互式 3D 视口调整虚拟相机的角度和距离，生成不同视角的图片。

### 三色手柄系统

- 🟢 **绿色手柄**（方位环）：控制水平旋转角度（0°~315°，45°步进）
- 🩷 **粉色手柄**（仰角弧）：控制垂直角度（-90°~90°，15°步进）
- 🟠 **橙色手柄**（距离线）：控制相机距离（0.6~4.0）

### 操作方式

- 拖拽 Canvas 中的彩色手柄调整参数
- 或使用下方的滑块精确调节
- 拖拽相机图标可同时调整三个参数
- 松开鼠标后自动吸附到最近的离散档位

### 使用步骤

1. 进入高级 → 3D 镜头控制
2. 点击「📷 加载图像」从 PS 截取当前选区
3. 调整相机角度和距离
4. 预览区底部显示当前参数的中文描述
5. 选择 API 引擎和参数
6. 点击「开始生成」

## 灯光编辑器

### 功能

添加多个虚拟光源，控制光照方向、类型、色温，生成不同打光效果的图片。

### 光源属性

| 属性 | 选项 |
|------|------|
| 光源类型 | 聚光 / 点光 / 面光 / 平行光 / 环境光 / 日照 / 自然光 / 月光 / 黄昏光 / 阴天光 |
| 布光角色 | 主光 / 补光 / 轮廓光 / 背光 / 侧光 |
| 光强 | 弱 / 中 / 强 |
| 曝光特效 | 无特效 / 高光溢出 / 过曝 |
| 颜色 | 色温 2000K~10000K 或 自定义颜色 |

### 使用步骤

1. 进入高级 → 灯光编辑器
2. 加载参考图像
3. 用滑块或手柄调整灯光方向
4. 选择光源属性
5. 点击「添加灯光」加入灯光列表
6. 重复 3-5 步添加更多灯光
7. 点击「开始生成」

## AI 自动调色

### 功能

将当前画面去色后交给 AI 重新上色，传回图层自动设为「颜色」混合模式。保留原画的细节精度，只改变色彩风格。

### 技术原理

1. 自动将画布扩展为 1:1 正方形（保证 AI 处理不变形）
2. 添加黑白调整层 → 截取去色后的图像 → 删除调整层 → 恢复画布
3. 将去色图像发送给 AI，附带用户的调色提示词
4. AI 返回上色后的图像
5. 再次扩展画布为 1:1 → 放置图层 → 设置混合模式为"颜色" → 裁切回原始尺寸

### 使用步骤

1. 进入高级 → AI 自动调色
2. 输入调色提示词（如"电影胶片质感"、"暖色调日落氛围"、"赛博朋克霓虹"）
3. 选择参数
4. 点击「开始调色」
