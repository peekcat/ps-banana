# 生成功能指南

## 提示词编写

### 基本原则

- 描述你想要 AI 对选区做什么修改，例如"让皮肤更光滑"、"把衣服变成红色"、"增加电影质感的光影"
- 支持中文和英文，中文会被 AI 理解
- 最大长度 20,000 字符

### 正则参数（@param 滑块）

部分预设包含 `@param` 标记，加载后会自动生成可调节的滑块：

```
@param:skin_smoothness": 0.50
```

- 滑块范围 0.00 ~ 1.00
- 拖动滑块会实时更新提示词中的数值
- 数值为 0 的模块在发送时会被自动跳过（`sanitizePrompt` 处理）
- 点击数值可手动输入精确值
- 鼠标滚轮可微调滑块

### AI 提示词优化

开启后（设置 → 输出 → AI提示词优化 → 开），提示词框上方会出现「AI优化」按钮：

1. 输入简短的中文意图
2. 点击「AI优化」
3. AI 返回结构化的中文方案（显示给你看）+ 隐藏的英文执行指令（实际发送给引擎）
4. 还会生成 3 个建议按钮供你点击迭代
5. 满意后点击「开始生成」，会使用优化后的英文指令

注意：
- 选择新预设或切换预设时，AI优化状态会自动清空
- 手动修改输入框内容后再点优化，会被视为全新请求

## 参数设置

| 参数 | 说明 | 建议值 |
|------|------|--------|
| 分辨率 | 生成图片的分辨率档位 | 日常用2K，高质量用4K |
| 数量 | 一次生成几张（1~18） | 1~3张，多张可对比效果 |
| 超时 | 等待API返回的最大秒数 | 120秒，4K可设更长 |

## 多任务并行

- 可以同时发起多个生成任务，每个任务显示为独立的卡片
- 每个卡片有：进度条、倒计时、+10s延时按钮、自动传回开关、停止按钮
- 最大并发 20 个 API 请求

## 抗截断模式

当图片被 AI 引擎误判为敏感内容而拒绝处理时：

- **抗截（模式1）**：对输入图像做色相偏移处理，降低被拦截概率，传回后自动还原
- **抗截+（模式2）**：在模式1基础上增加垂直翻转，进一步降低拦截概率

注意：抗截模式会轻微影响画质，仅在被拦截时开启。

## 自动传回

- 默认开启，生成完成后自动将图片贴回 PS
- 可以点击任务卡片上的 ✓/□ 按钮切换单个任务的自动传回
- 顶栏的「✓回传」按钮控制全局默认值
- 如果 PS 正在操作中（画笔、对话框等）导致自动传回失败，图片会被缓存，任务卡片显示 ▶ 按钮供手动传回

## 参考图

- 最多添加 4 张参考图
- 点击「添加参考图」后，PS 会截取当前选区作为参考图
- 参考图会连同主图和提示词一起发送给 AI
- 主要用于风格参考或细节指引
