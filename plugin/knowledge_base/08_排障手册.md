# 排障手册

## 一、API 报错速查表

### HTTP 状态码

| 状态码 | 常见原因 | 解决方法 |
|--------|---------|---------|
| 400 | 提示词格式错误、上下文过长、参数非法 | 检查提示词内容，缩短过长的文本 |
| 401 | API Key 无效或未填写 | 检查设置中的 API Key 是否正确 |
| 402 | 中转站余额不足 | 充值或切换供应商 |
| 403 | 权限不足、模型不可用、地区限制 | 检查 Key 权限，尝试切换模型 |
| 404 | 模型名称错误或未映射 | 确认模型名称正确 |
| 413 | 请求体过大 | 降低压缩分辨率，减少参考图数量 |
| 429 | 请求过快、并发超限、额度耗尽 | 降低并发数，等待后重试 |
| 500 | 服务内部错误 | 稍后重试 |
| 502 | 中转站连不上上游 | 检查网络，稍后重试 |
| 503 | 服务过载、无可用渠道 | 切换模型或供应商，稍后重试 |
| 504 | 响应超时 | 增加超时时间，降低分辨率 |

### 内容被拦截（200 但无结果）

| 表现 | 原因 | 解决方法 |
|------|------|---------|
| 生成失败：内容可能被拦截 | 图片触发安全审查 | 开启抗截断模式，或对敏感区域打码 |
| API 未返回图片数据 | 安全过滤或内容审查 | 修改提示词，避免敏感描述 |
| 返回空内容 | 上游安全策略拦截 | 使用抗截断模式 |

### 常见错误消息

| 错误信息 | 原因 | 解决方法 |
|---------|------|---------|
| 提示词未填写 | 输入框为空 | 输入提示词或加载预设 |
| API Key 未填写 | 设置中未配置 Key | 去设置标签页填写并保存 |
| API 地址未填写 | 设置中未配置地址 | 填写 API 地址 |
| 请求超时 | AI 处理时间超过设定的超时 | 点击 +10s 延时，或增大超时值 |
| 网络连接失败 | 无法访问 API 服务器 | 检查网络连接和代理设置 |

## 二、PS 操作问题

### 图片没有传回

**症状**：任务卡片显示完成但图片没有出现在 PS 图层面板中

**原因**：PS 正在执行用户操作（画笔、变换、对话框等），插件无法获取控制权

**解决方法**：
1. 停止所有 PS 操作（不要画画、不要开对话框）
2. 任务卡片会显示 ▶ 按钮
3. 点击 ▶ 手动传回
4. 或者等下次任务自动传回

### 选区不对齐

**症状**：传回的图片位置偏移

**解决方法**：
1. 确保在生成前用矩形选框工具画好选区
2. 不要在生成过程中移动画布或修改选区
3. 如果文档被关闭后重新打开，需要重新生成

### 打开文件夹失败

**症状**：点击"打开预设文件夹"等按钮没反应

**解决方法**：
1. 查看日志中显示的文件夹路径
2. 手动在文件管理器中访问该路径
3. 插件会尝试 3 种方式打开文件夹（shell.openPath → shell.openExternal → 显示路径）

## 三、Forge 连接问题

### 连接失败

| 错误信息 | 原因 | 解决方法 |
|---------|------|---------|
| SD WebUI 可能未启动 | Forge 没运行 | 启动 Forge WebUI |
| 端口/地址错误 | URL 填写有误 | 确认端口号（默认 7860） |
| 服务器有响应但返回错误状态码 | Forge 配置问题 | 在浏览器中直接访问 Forge 地址确认可用 |
| 未检测到选区 | PS 中没有画选区 | 先用选框工具框选区域 |

### 云 Forge 问题

| 问题 | 解决方法 |
|------|---------|
| 积分不足 | 登录后查看积分余额，使用卡密充值 |
| 连接断开 | 重新点击「连接」 |
| 生成失败 | 检查网络连接，确认积分充足 |

## 四、ComfyUI 连接问题

| 问题 | 解决方法 |
|------|---------|
| 连接失败 | 确认 ComfyUI 已运行，默认地址 `http://127.0.0.1:8188` |
| URL 为空 | 在连接栏输入 ComfyUI 地址 |
| 未加载工作流 | 连接成功后从下拉菜单选择工作流 |
| 参数 UI 为空 | 确认工作流中有 `@37` 前缀的节点 |

## 五、聊天助手问题

| 问题 | 解决方法 |
|------|---------|
| 聊天面板跑到屏幕外 | 设置 → 聊天助手 → 点击「归位」 |
| 无法发送消息 | 检查聊天设置中的 API 地址/Key/模型 |
| 回复为空 | 可能触发了内容过滤，修改提问方式 |
| 模型列表为空 | 点击「拉取」按钮重新获取模型列表 |

## 六、性能问题

| 问题 | 解决方法 |
|------|---------|
| 插件卡顿 | 设置 → 外观 → 开启「简洁模式」 |
| 内存占用高 | 清空图片缓存（设置 → 输出 → 清空缓存） |
| PS 响应慢 | 减少同时运行的任务数量 |

## 七、日志查看

- 点击插件底部的日志栏展开查看详细日志
- 日志包含所有操作的时间戳、状态和错误信息
- 遇到问题时可以截图日志发给开发者排查
