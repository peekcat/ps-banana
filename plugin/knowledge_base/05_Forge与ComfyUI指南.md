# Forge 与 ComfyUI 指南

## SD WebUI Forge

### 什么是 Forge？

Forge 是 Stable Diffusion WebUI 的一个分支，可以在本地运行 SD 模型。插件支持直接从 PS 调用 Forge 进行 img2img 和 txt2img 操作。

### 开启 Forge 模式

设置 → 功能开关 → Forge 模式 → 开启

### 连接本地 Forge

1. 确保 Forge WebUI 已在本地运行（默认地址 `http://127.0.0.1:7860`）
2. 切换到 Forge 标签页
3. 在地址栏输入 Forge 地址
4. 点击「保存 & 连接」
5. 连接成功后会自动加载模型列表、采样器、LoRA 等

### 连接云端 Forge

1. 在 Forge 标签页点击「登录」
2. 使用邮箱注册/登录云服务
3. 登录后点击「连接」
4. 云 Forge 使用积分计费

### Forge 参数

| 参数 | 说明 | 范围 |
|------|------|------|
| 模型 | SD 模型 | 从 Forge 获取 |
| 采样器 | 采样方法 | DPM++ 2M 等 |
| 调度器 | 噪声调度 | Automatic/uniform/karras/exponential |
| 步数 | 采样步数 | 1~150 |
| CFG | 提示词引导强度 | 1~30 |
| 重绘幅度 | img2img 变化程度 | 0~1 |
| 批次大小 | 一次生成数量 | 1~8 |
| 分辨率 | 输出分辨率 | 自定义 |
| Seed | 随机种子 | -1为随机 |
| LoRA | 额外模型 | 可选+权重 |
| ControlNet | 控制网络 | 预处理器+模型+权重 |

### Forge 分辨率逻辑

面板上设置的分辨率控制**宽边**的像素数，窄边按原始比例等比缩放。例如：
- 面板分辨率设 1200，原图选区 2400×4800 → Forge 参数为 1200×2400

### 翻译功能

Forge 标签页有翻译输入框，输入中文后点击翻译按钮（通过有道翻译 API），翻译结果可追加到正向或反向提示词。

## ComfyUI

### 什么是 ComfyUI？

ComfyUI 是一个基于节点/工作流的 Stable Diffusion 界面。插件支持加载 ComfyUI 工作流并动态生成参数 UI。

### 开启 ComfyUI 模式

设置 → 功能开关 → ComfyUI 模式 → 开启

### 连接 ComfyUI

1. 确保 ComfyUI 已在本地运行（默认地址 `http://127.0.0.1:8188`）
2. 切换到 ComfyUI 标签页
3. 输入地址并点击「保存 & 连接」
4. 连接成功后自动加载工作流列表

### 使用工作流

1. 从下拉菜单选择工作流
2. 插件会解析工作流并生成参数 UI
3. 调整参数
4. 点击「ComfyUI 生成」
5. 支持中断操作

### 工作流参数命名规范

工作流中的节点标题以 `@37` 前缀标记的会被自动识别为可调参数。可以通过「全部节点」开关查看所有节点。
