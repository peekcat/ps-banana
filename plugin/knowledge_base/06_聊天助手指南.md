# 聊天助手指南

## 功能概述

插件内置了一个 AI 聊天助手，通过画面右下角的 💬 浮动气泡访问。可以用来：
- 询问修图技巧
- 让 AI 帮你写提示词
- 分析图片并给出修改建议
- 日常 AI 对话

## 打开与关闭

- **点击** 💬 浮动气泡打开聊天面板
- **拖拽** 气泡可以移动到画面四边停靠
- 面板右上角 × 关闭
- 面板可以拖拽标题栏移动位置，拖拽边缘调整大小
- 位置和大小会自动保存

## 首次使用

首次打开会进入引导流程：
1. 自动拉取可用模型列表
2. 选择要使用的 AI 模型
3. 选择一个聊天身份/角色

## 配置 API

聊天助手有独立的 API 配置（不影响主插件的生成 API）：
1. 点击聊天面板标题栏的 ⚙️ 按钮
2. 填写 API 地址和 API Key
3. 点击拉取模型并选择模型
4. 如果不填，会自动使用主插件设置中的 API 配置

## 内置角色

插件预装了 9 个专业角色：

| 角色 | 擅长 |
|------|------|
| 🛠️ 通用助手 | 通用修图建议和提示词生成 |
| 🎨 风格大师 | 艺术风格转换 |
| 📸 摄影师 | 摄影后期、调色 |
| ✨ 美颜专家 | 人像美颜、磨皮、化妆 |
| 🏠 场景设计师 | 背景替换、场景合成 |
| 🔧 修复师 | 图像修复、水印去除 |
| 🎭 表情包制作 | 表情包和贴纸创作 |
| 📝 提示词优化师 | 提示词优化和改进 |
| 🧬 夏三七 | 专业提示词工程师（含完整工程规范） |

### 自定义角色

- 点击 🎭 身份切换按钮
- 点击「创建」新角色
- 设置图标、名称、描述、系统提示词
- 可以编辑或隐藏内置角色

## 会话管理

- 最多 10 个独立会话，每个会话最多 20 条消息
- 点击 📋 按钮查看会话列表
- 点击 ➕ 新建会话
- 会话数据保存在本地，跨会话切换不会丢失

## 图片附件

- 最多 4 张图片附件
- 来源：点击附件按钮从 PS 截取当前选区
- 图片会随消息一起发送给 AI 进行分析

## JSON 代码块

当 AI 回复中包含 JSON 代码块时，聊天面板会：
- 自动识别并格式化显示
- 提供「复制」按钮
- 提供「填入提示词」按钮，一键将内容填入主插件的提示词框

## 新手教程

聊天面板内置了 10 章新手教程，可以通过设置标签页的「新手教程」区域打开，也可以通过聊天助手的引导流程开启。
