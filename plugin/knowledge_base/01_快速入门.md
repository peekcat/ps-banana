# 快速入门

## 什么是修图轮椅？

夏三七的修图轮椅是一款 Photoshop 插件，让你在 PS 中直接使用 AI 进行图片生成和编辑。无需切换软件，框选区域、输入提示词、点击生成，AI 处理完的图片自动贴回 PS 的对应位置。

## 安装步骤

1. 确保 Photoshop 版本 ≥ 26.0.0（PS 2025 或更新）
2. 打开 UXP Developer Tool（PS菜单 → 增效工具 → UXP开发者工具）
3. 点击"添加插件"，选择插件文件夹中的 `manifest.json`
4. 插件面板会出现在 PS 窗口中，可以拖拽停靠到任意位置

## 首次配置

### 第一步：填写 API Key

1. 打开插件 → 切换到「设置」标签页
2. 在「连接」区域选择 API 供应商（默认 AJI）
3. 填入 API Key 并点击「保存 Key」
4. 如果使用 GRS 供应商，切换到 GRS 面板填写 GRS Key

### 第二步：确认能正常工作

1. 在 PS 中打开任意一张图片
2. 用选框工具框选一块区域
3. 切换到插件的「生成」标签页
4. 在提示词框输入"让画面更清晰"
5. 点击「开始生成」
6. 等待任务完成（进度条会显示在任务卡片中）
7. 生成的图片会自动贴回 PS 对应位置

## 基本操作流程

```
框选区域 → 输入提示词 → 选择参数 → 点击生成 → 等待 → 图片自动传回PS
```

## 界面概览

插件有 6 个主要标签页：

| 标签 | 功能 |
|------|------|
| 生成 | 核心功能，输入提示词生成/编辑图片 |
| 批处理 | 多任务队列管理 |
| Forge | SD WebUI Forge 本地模型调用（需要在设置中开启） |
| ComfyUI | ComfyUI 工作流调用（需要在设置中开启） |
| 高级 | 全局分区、分块放大、3D镜头、灯光编辑器、AI调色 |
| 设置 | API配置、输出设置、外观自定义 |

另外还有一个**浮动聊天助手**（画面右下角的💬气泡），可以进行 AI 对话。

## 快捷操作

- **滚轮调参**：在模型/分辨率/数量/超时等下拉框和数字框上滚动鼠标滚轮即可快速调节
- **预设快速加载**：点击人体剪影上的身体部位，自动加载对应区域的预设
- **历史提示词**：点击🕐按钮查看并复用之前用过的提示词
- **预设搜索**：点击🔍按钮快速搜索预设库
