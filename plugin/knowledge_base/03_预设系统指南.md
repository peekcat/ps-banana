# 预设系统指南

## 预设是什么？

预设是预先编写好的专业提示词模板，让你不需要自己写复杂的英文提示词。点击预设就能自动填入优化过的提示词，部分预设还带有可调节的参数滑块。

## 出厂预设

插件内置了 121 个标准预设和 15 个 Forge 预设，覆盖：

- **面部**：精修、磨皮、修容（自然/厚涂/CG风）、补妆、瞳孔、眼妆、鼻梁高光、唇纹、眉形、下颌线
- **面部风格**：御姐脸、萝莉脸、美男脸、成熟男性、少年感、邪魅风、清冷仙侠
- **身体**：全身修饰、手臂、手部、腿部、颈部
- **头发**：发型调整、发色、发质
- **服装**：衣物材质、颜色调整
- **配饰**：饰品添加
- **背景**：场景替换、环境修饰
- **光影**：光照调整、氛围营造

## 人体剪影预设选择器

生成标签页下方有一个人体剪影图：

1. 点击身体的某个部位（如脸部、手臂、腿部）
2. 自动显示该区域对应的所有预设
3. 点击预设名称即可加载到提示词框
4. 支持收藏（星标），收藏的预设会排在最前面

## 自定义预设

### 保存预设

1. 在提示词框中编写好提示词
2. 点击保存按钮
3. 输入预设标题
4. 预设保存到本地文件夹

### 管理预设

- 设置 → 预设管理 → 打开预设文件夹：可以手动编辑 JSON 文件
- 设置 → 预设管理 → 刷新：重新扫描预设文件夹
- 支持导入/导出预设

### 预设 JSON 格式

```json
{
  "title": "预设名称",
  "content": "提示词内容...",
  "category": "head",
  "refImages": []
}
```

## Forge 预设

Forge 预设包含完整的 Stable Diffusion 参数：
- 正向/反向提示词
- 模型、采样器、步数
- ControlNet 配置
- LoRA 配置
- 分辨率和重绘幅度

加载 Forge 预设时，生成按钮会切换为 Forge 模式，直接调用本地或云端的 SD WebUI 生成。

## 预设搜索

点击提示词框上方的 🔍 按钮，打开搜索浮层，输入关键词快速筛选预设。
