# 设置与外观指南

## 连接设置

### API 供应商切换

三个供应商各有独立的 Key 和地址：

- **AJI**（默认）：使用 `https://ai.ajiai.top`，按张计费
- **GRS**：使用 `https://grsai.dakka.com.cn`（国内）或 `https://grsaiapi.com`（海外），积分计费
- **Others**：自定义 OpenAI 兼容 API，支持多个配置方案

### 保存 API Key

填写 Key 后点击「保存 Key」，Key 会持久化存储，重启 PS 不丢失。点击「清空」可以清除已保存的 Key。

## 输出设置

### 图层类型

- **栅格化**：生成的图层为普通像素图层
- **智能对象**：生成的图层为智能对象（推荐，便于后续无损调整）

### 自动编组

开启后，多张生成结果会自动放入一个 PS 图层组中。

### 传回边缘羽化

开启后，传回的图层边缘会有羽化过渡效果，和原图融合更自然。可以单独选择对哪些工作流生效：
- banana 单图 / banana 批处理 / 分块放大 / Forge / ComfyUI

羽化参数：
- 内缩比例（0~50%）：从边缘向内收缩的程度
- 模糊比例（0~50%）：边缘模糊的程度

### 压缩分辨率

控制发送给 API 的图片最大边长（512~4096px）。数值越大图片越清晰但请求越慢、费用越高。预设值：1024 / 1536 / 2048 / 3072。

### 图片格式

- **PNG 压缩**：无损格式（默认）
- **JPEG**：有损格式，文件更小，可设质量（50~100）

## 功能开关

### 胶囊按钮

生成/批处理/参考图按钮的显示模式：
- **开启**：浮动在画面上的可拖拽胶囊
- **关闭**：固定在面板底部的标准按钮
- **卫星**：按钮转移到「轮椅遥控器」卫星插件

### 队列位置

任务进度卡片显示位置：
- **顶部**：显示在提示词上方
- **下方**：显示在按钮区域
- **卫星**：转移到卫星插件

### 无选区自动全图

开启后，如果没有画选区就点击生成，会自动截取整个画布。

### 滚轮调参

开启后，鼠标滚轮可以在下拉框和数字输入框上快速调节参数值。

## 外观自定义

### 简洁模式

开启后去除所有动画、背景图、毛玻璃效果，使用纯色背景，适合低配电脑。

### 主题色

点击色块或输入 HEX 值自定义插件的主题强调色。预设 7 种颜色可选。

### 背景图

- 点击「选择」加载自定义背景图
- 支持调整焦点位置（X/Y 偏移）
- 支持背景缩放（100%~300%）
- 支持不透明度调节
- 支持高斯模糊（0~30px）

### 界面缩放

整体 UI 缩放比例（80%~200%），适配不同分辨率显示器。

### 文字模式

浅色 / 深色 / 自动，控制文字颜色适配不同背景。

## 音效

可以为以下事件设置音效：
- 任务完成时
- 全部任务报错时
- 单个任务报错时

音效文件放在插件的 `/audios/` 文件夹中，内置 11 个音效文件。

## 余额追踪

开启后在面板底部显示剩余余额。支持：
- 手动校准余额
- 查询服务端余额
- 设置低余额警告阈值（默认 $0.50）
