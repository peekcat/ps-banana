## 任务 3：新手引导遮罩改回原版行为

**决定**（使用者已确认）：回退上一轮对 `tiles/tile-tutorial.css` 的改动。

**理由**：原版的设计是讲解步骤遮罩挡点击、只能点气泡（气泡里有「跳过引导」），交互步骤才放行。上一轮把所有步骤都改成能点穿，讲解步骤里用户也能点收磁贴、切页签，而步骤的 `onEnter` 会自动展开磁贴、对准元素，容易对不上。「遮罩挡按钮是原版 bug」这个说法出自交接文档，当时没有查到具体是哪一步挡了哪个按钮。

**做法**：

1. 把 `tiles/tile-tutorial.css` 恢复成 `main` 上的样子：
   ```powershell
   git checkout origin/main -- plugin/tiles/tile-tutorial.css
   ```
2. 清空数据重装，把主线引导完整走一遍。
3. 如果某一步**确实要用户点底下的界面却点不到**，只给那一步加交互标记（和原版其他交互步骤同样的写法），并在记录里写明是哪一步、点的是什么。预计一步都没有：会卡住的步骤（指向已删区域的）A5 已经删掉了。
