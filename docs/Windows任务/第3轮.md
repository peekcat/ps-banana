## 任务 1：海报 `_WC_SECRET` 被误删（确定的 bug）

**问题**：`972ad64` 删图床代码时，把 `tiles/tile-poster.host.js` 里的 `var _WC_SECRET = ...` 一起删了，但 `_signBody`（约 114 行）还在用。`node --check` 查不出来，运行到就报 `ReferenceError`：

- 海报「自动填充」：界面会显示 `_WC_SECRET is not defined`，比原版的网络失败还难懂；
- `posterReportUsage`：被外层 `try` 吞掉，看不出来。

**做法**：

1. 把这一行和它上面「纯 JS SHA-256」那行注释恢复成 `972ad64^` 的样子（`git show 972ad64^:plugin/tiles/tile-poster.host.js` 对照）。这两个功能阶段 B 会整体重写，这里只求恢复原样，不要顺手改别的。
2. 原来「海报参考图临时图床(给 GRS 流用…)」那行注释现在挂在 `_sha256` 上面，删掉。
3. 自查：同一批提交里删掉的其他变量，还有没有别处在用。至少搜一遍：
   ```powershell
   Get-ChildItem plugin -Recurse -File -Filter *.js | Select-String -Pattern '_WC_SECRET|_readDeviceId|POSTER_TEMP_UPLOAD_PATH|_grsPreUrls|grsUrls|shutProgress|serverConfig'
   ```
   每一处命中都要能说清楚：定义在同一个文件里，或者确实不需要。`tile-run.host.js` 删掉了 `serverConfig` 的 `require`，要确认这个文件里已经没有 `serverConfig.` 了。

**验证**：海报磁贴点「自动填充」，提示应当和阶段 A 时一样是网络 / 服务不可用一类，不出现 `is not defined`。

## 任务 2：GPT-Image 纯文生图不要在底层拦住

**问题**：`host/ai-api.js` 的 `callGrsGptImageApi` 现在没有参考图就直接报错「GRS + GPT-Image 需要至少一张参考图」。单图磁贴 `tile-run.host.js` 自己有这道检查（原版就有），没问题；但画布、拼接、批量等其他磁贴也走这个函数，它们用 GRS + GPT-Image 不带图时，原版能纯文生图，现在被拦住了。

**做法**：

1. 删掉 `callGrsGptImageApi` 里的那段 `throw`；`images` 为空时**不放这个字段**，有图才放。
2. `tile-run.host.js` 原有的检查保留，不动。
3. 用下面「验证」里那次真实调用确认：新接口不带 `images` 能出图（官方文档里 `images` 不是必填，但没实测过；`tools/grs_probe.py` 目前只有带图的用例，不用为此改脚本）。如果不带 `images` 会报错，就在记录里写明，并回退这一步。

**验证**：找一个不带图也能调用 GPT-Image 的磁贴（例如画布），GRS + `gpt-image-2` 1K 纯文生图出一张。

## 任务 4：补测（阶段 C 验收里还空着的）

每项结果写进记录；失败就记下提示原文，**有没有出图、有没有扣积分**。

1. **海报 + GRS + GPT-Image**（阶段 C 验收第 2 条）：
   - 先用 2–3 张参考图出一页，确认成功、结果确实参考了这些图。
   - 再试一页**参考图尽量多**的（海报允许的上限，原注释写的是 16 张），记下张数和请求体大约多大（日志里有每张的 KB）。海报参考图本身已经压到 1024 长边 JPEG，问题在于现在所有图塞进**一个**请求，以前是一张张传图床。服务端能接受多大的请求没人测过。
   - 如果多图失败，提示是否看得懂（例如 413「请求体过大」），而不是静默跳过。**先别改代码**，把结果带回来再定怎么处理。
2. **其他磁贴的大图**：挑一个会带参考图的非单图磁贴（例如分块或批量），GRS + GPT-Image，用一张较大的选区出图。这些磁贴不经过 1.2MB 压缩。成功就记一下图片多大；失败就记提示原文。同样**先别改代码**。
3. **断网**（阶段 C 验收第 5 条）：两种时机各一次。① 提交前就断网；② 提交成功、进入轮询之后再断网（日志出现「进入轮询」后断网卡）。记下提示原文；轮询中断网要确认最终会报错结束，任务卡不会一直转圈。恢复网络后查一次余额，看有没有扣费。
4. **违规（`violation`）**：不要刻意构造违规内容。用一张普通真人照片（人像）做参考图试一次，能触发就记提示原文，不触发就在记录里写「未触发，代码路径靠审阅」。
5. **Network 证据**（阶段 C 验收第 3 条）：做一次 GPT-Image 带选区出图时，在 UDT DevTools → Network（**All**，不是 XHR）里列出请求域名，应当只有 GRS 节点和结果图片的域名。
6. **回归**（阶段 C 验收第 6 条）：GRS + Banana 带选区出一张。
