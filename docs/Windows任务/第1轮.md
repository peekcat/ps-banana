## 任务 1：在代理规则里屏蔽作者域名

**为什么**：这台机器开着系统代理 `127.0.0.1:7892`。请求走 HTTP 代理时，域名在代理端解析，**hosts 不起作用**。上一轮看到的 `Network request failed` 也可能只是作者服务器本来就停了，证明不了 hosts 屏蔽生效。

**做法**（Agent 可做）：

1. 确认是哪个代理软件：

   ```powershell
   Get-NetTCPConnection -LocalPort 7892 -State Listen |
     ForEach-Object { Get-Process -Id $_.OwningProcess } | Select-Object Name, Path
   ```

2. 用该软件**持久的覆写 / 扩展规则功能**加三条规则，放在所有规则最前面。不要直接改订阅文件，订阅一刷新就没了。Clash / mihomo 的写法：

   ```yaml
   - DOMAIN,xiasanqi.cpolar.top,REJECT
   - DOMAIN,xiasanqiforge.vip.cpolar.cn,REJECT
   - DOMAIN,qwentest.vip.cpolar.top,REJECT
   ```

   是 Clash Verge 系的话，用「扩展覆写配置 / Merge」的 `prepend-rules`；其他客户端用它自己的等价功能。拿不准就停下，把软件名和版本写进记录，交给人处理。

3. 验证（三个域名都要测）：

   ```powershell
   # 走代理: 应当立即失败 (连接被拒/被关闭), 而不是拿到任何 HTTP 状态码或超时
   curl.exe -sS -m 10 -x http://127.0.0.1:7892 -o NUL -w "%{http_code}`n" https://xiasanqi.cpolar.top/
   # 不走代理: 应当连到 0.0.0.0 失败
   curl.exe -sS -m 10 --noproxy "*" -o NUL -w "%{http_code}`n" https://xiasanqi.cpolar.top/
   ```

   然后在代理软件里**手动刷新一次订阅**，再测一遍，确认规则还在。

4. 顺带确认 **UXP 插件的请求走不走系统代理**：在 UDT 里 Reload 插件，看代理软件的「连接 / 日志」页有没有出现这三个域名（被 REJECT 的记录）。有或没有都写进记录，以后判断问题时要用。

## 任务 2：6.6.4 停服基线

前提：任务 1 已验证通过。在 `win-test` 上（代码和 `main` 一致）用 UDT Reload 插件，DevTools 打开 **Console** 和 **Network**。

**分工**：在 PS 和插件里点的操作由**人**做；Agent 负责查余额、抓日志、整理记录。

**花钱的项**：第 4 项会出几张图（几千积分）。出图前后各查一次余额：

```powershell
$env:GRS_API_KEY = "<key>"          # 只设在当前窗口, 不写文件, 不进记录
python tools/grs_probe.py credits
```

在插件设置里把服务商配成 GRS（BYOK），线路用默认的 `grsai.dakka.com.cn`。

**逐项记录**：结果（正常 / 报错 / 卡住 / 静默无反应）+ Console 报错原文 + Network 里打向三个被屏蔽域名的请求。

| # | 项目 | 预期 |
|---|---|---|
| 1 | 插件启动，面板正常显示 | 正常 |
| 2 | 启动后 30 秒内 Network 里打向被屏蔽域名的请求（全部列出：URL + 发起位置） | 有：会话恢复、公告、AJI 地址列表、Momo 链接等 |
| 3 | 本地预设、布局能加载 | 正常 |
| 4a | GRS + **Banana** 模型：文生图 | 正常 |
| 4b | GRS + **Banana** 模型：带选区的图生图 | 正常（图片直接放在请求里，不经图床） |
| 4c | GRS + **GPT-Image** 模型：纯文生图（不带图） | 正常 |
| 5 | GRS + **GPT-Image** 模型：带选区的图生图 | **失败**：卡在「上传图床」，或者报「请先打开过客服磁贴」 |
| 6 | 本地 Forge | 未测（无 N 卡） |
| 7 | 本地 ComfyUI | 未测（无 N 卡） |
| 8 | 登录 / 注册（只点开看反应，不用真的注册） | 失败 |
| 9 | 翻译、提示词优化、海报自动填充 | 失败 |
| 10 | 磁贴：同步、更新、客服、服务器状态、DLSS、Qwen2.1 | 失败或要求登录 |
| 11 | 网络诊断磁贴 | 「夏三七正式服务器」一项失败，其余正常 |

**第 5 项要特别看清楚**，这是后面 C 阶段改造的对照组：

- 失败发生在哪一步、界面上给用户的提示原文是什么；
- **有没有出图、有没有扣积分**。按代码（`host/ai-api.js:1297`），上传失败后可能会**忽略参考图继续出一张图**。如果出了图，记下这张图和选区内容有没有关系。
